# Flappy Bird
 
This project is a replica of the Flappy Bird game built in Python using object-oriented programming and the pygame library.
 
The application must be started locally (see the "Running locally" section)
 
Note: Python and the pygame library must be installed.
 
## Tech stack
 
![Python](https://img.shields.io/badge/-Python-333333?style=for-the-badge&logo=python)
![Pygame](https://img.shields.io/badge/-pygame-333333?style=for-the-badge&logo=python&logoColor=yellow)
 
## Running locally
 
Clone the project
 
```bash
  git clone https://github.com/Caique27/Flappy-Bird.git
```
 
Go to the project directory
 
```bash
  cd Flappy-Bird
```
 
Start the application
 
```bash
  python FlappyBird.py
```
 
## Application demo
 
![](./demo.gif)
 
-   The user interacts with the application by using the space bar to control the bird. The goal is to get through the pipes without touching them.
